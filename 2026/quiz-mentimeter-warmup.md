# Warm-up quiz — Mentimeter

5 questions, anonymous, no wrong answers. Create each as a plain **Poll**
slide (not Quiz Competition — there's no correct answer to score). Shows
you where the room stands before Block 01.

---

**1. Have you written a Dockerfile before?**
- A) Never
- B) Once or twice
- C) Regularly

**2. Have you deployed something to a cloud account?**
- A) Never
- B) With help / a template
- C) On my own

**3. Do you know what a CI pipeline does?**
- A) No idea
- B) Roughly, yes
- C) I've built one

**4. Have you used Terraform or similar IaC?**
- A) Never heard of it
- B) Seen it, not used it
- C) Used it

**5. Where do you keep secrets today?**
- A) Not sure / never needed to
- B) .env file or similar
- C) A secret manager
